## 📄 Descrição do entregável

Este projeto consiste no desenvolvimento de um website moderno e responsivo para uma agência de viagens e turismo.

O projeto tem como objetivo apresentar uma experiência visual voltada para descoberta de destinos, experiências e pacotes turísticos.

O entregável será desenvolvido utilizando React + Vite, com componentes reutilizáveis e uma estrutura organizada para facilitar futuras expansões.

---

<!-- ---------------------------------------------------------------------- -->

## 💻 Sobre o projeto

**Viajare** é um projeto desenvolvido como estudo e prática de desenvolvimento Front-End utilizando **React + Vite**.

O projeto tem como objetivo criar um modelo de website para uma agência de viagens e turismo, utilizando como referência visual uma interface desenvolvida previamente no **Google Stitch**.

A proposta é desenvolver uma experiência moderna, visual e responsiva, utilizando imagens de destinos turísticos como parte importante da composição da interface.

O projeto também tem como objetivo praticar conceitos importantes do ecossistema React, como:

* Componentização
* Props
* State
* Renderização de listas
* Eventos
* Organização de componentes
* Separação de dados
* Estruturação de projetos React
* Responsividade
* Reutilização de componentes

A aplicação será estruturada de forma que futuramente possa receber novas funcionalidades, como páginas individuais de destinos, sistema de reservas, integração com API, banco de dados e área administrativa.

## 🚀 Como executar o projeto

### 1 - Clonar o repositório

```bash
git clone https://github.com/seu-usuario/travel-agency.git
```

### 2 - Entrar na pasta do projeto

```bash
cd travel-agency
```

### 3 - Instalar as dependências

```bash
npm install
```

### 4 - Rodar o projeto

```bash
npm run dev
```

O Vite disponibilizará o projeto localmente em um endereço semelhante a:

```text
http://localhost:5173/
```
